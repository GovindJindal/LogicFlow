AIM

Objective

To design and simulate an Arithmetic Logic Unit (ALU). Configure inputs and select modes to observe data routing through arithmetic and logic sub-units via the multiplexer.

THEORY

Working Principles

An Arithmetic Logic Unit (ALU) is the part of a computer processor (CPU) that carries out arithmetic and logic operations on the operands in computer instruction words. The ALU is divided into an Arithmetic Unit and a Logic Unit, with a multiplexer selecting between their outputs based on a Mode line.

PROCEDURE

How to Perform the Experiment

  • Navigate to the Simulation tab.
  • Toggle the Mode (M) switch to select between Arithmetic (M=0) and Logic (M=1) operations.
  • Toggle the Select Lines (S) to pick a specific operation.
  • Set the Input A and Input B values and observe how the output Y changes.
  • Observe the active paths lighting up in the macro architecture diagram.
